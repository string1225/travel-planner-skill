# 本地旅行规划 skill 方案

## 目标与入口

新增本地可发现的 `travel-planner` skill，安装到用户的 Codex skills 目录。适用于“规划旅行并做成带真实参考材料的线路视频”，也支持仅调研或仅输出行程。现有 `video-report` 继续负责旁白、完整句字幕、基础画面和发布；新 skill 负责旅行查询、材料来源和混合剪辑的交接。当前B站稿件是独立的既有任务，不因创建此 skill 自动重传或另发一条。

## 方案比较

| 方案 | 能力与代价 |
|---|---|
| 仅编排说明 | 轻量，但素材整理和混合剪辑仍需临时重写 |
| 编排说明＋少量可执行工具（采用） | 复用高德、飞猪、Ego和video-report，补齐依赖检查、来源清单和媒体编排；适合本地重复使用 |
| 单独开发全自动抓取和发布应用 | 站点适配和维护面过大，不作为本次目标 |

## 输入与查询

记录日期、起终点、人数与儿童年龄、交通方式、住宿房间数、预算和兴趣；能从同任务获取的参数不再询问。仅问会影响查询的缺项，例如查机票确实需要的出发机场、日期和人数。

检查并按需安装官方 FlyAI 与指定高德 skill；复用已有安装和私有配置，密钥由环境变量或供应商私有配置读取，不进入技能文件、研究文件或视频交付包。默认健康检查不收费查询，实际查询用于任务所需的少量样本。

先查沿途各城市及景点候选，再核对官方公告、儿童规则与当季营业。高德核对POI、驾车路线、里程和真实地图画面；FlyAI按日期查询机票、酒店或门票，将成人儿童条件和报价范围一起记录。查询时间与旅行日期分开，展示价不能写成已锁价或可售总价。

## 社交平台取材

使用Ego Lite的同一任务空间，搜索小红书景点介绍和B站相关视频。登录、验证码、浏览器权限和用户接管按Ego规则处理；用户处理后恢复原空间。登录受限时记录缺项，继续官方查询、路线和原创脚本工作。

将笔记观点与官方事实分开：笔记可帮助发现机位、步行体验、排队线索和季节体验，不能单独证明未来营业与报价。记录作者、标题、原文链接、发布时间（可见时）、截取时间和所支持的论点。

可保存浏览器可见的相关截图；视频通过平台允许的下载、作者提供文件或可访问的公开媒体路径获取，保留水印与署名，不绕过付费、DRM、访问限制或验证码。长片重用需要相应依据；围绕景点介绍作必要短引述时注明用途和出处，不把引用自动算作自制素材。权利或取得方式不清时，保留链接并用原创图示承接，不伪称已取得原视频。

## 素材与剪辑

每个任务保存机器可读来源清单、报价记录和分镜时间线。素材类型包括：原创文字图示、高德实查地图截图、报价截图、小红书相关摘录截图、B站景点短片及用户素材。清单记录本地文件、来源、使用依据、片段时间和状态，排除凭证、Cookie和无关个人内容。

复用video-report生成旁白、完整句字幕与时间轴。新增本地FFmpeg媒体编排辅助工具，把指定片段放入相应场景，默认使用统一旁白、静音原片声音，保留来源标签、画面安全区和字幕空间；仅为适配画布做等比缩放、留白，不裁掉水印或改变引用意义。缺素材时用对应原创画面，并在记录中写明替代情况。

视频交付包含MP4、可编辑HTML、行程、来源、素材清单、时间线、字幕、QA和制作成本。实际使用的各类素材都要抽帧检查，最终全片解码，检查画面比例、字幕、来源标注与片段时长。无法实际验证的平台流程如实标记。

## 发布边界

用户明确要求发布时调用video-report维护的发布入口，并复用当前任务的授权。引用外部材料的成片不能因AI剪辑就自动勾选“自制”；根据最终使用材料及平台规则核对声明。最终提交后读取平台回执；没有回执时记录“发布未确认”，不反复点投稿或创建替代稿来猜结果。

## 验证与完成条件

依赖检查能发现现有高德、FlyAI、Ego、video-report和本机媒体工具，且不输出密钥。来源清单拒绝缺来源的引用、缺日期条件的锁价主张和无文件的“已取得”状态。短样例能把图片、视频片段和原创场景混合为MP4，保留旁白字幕时间轴并全片解码。技能结构校验通过，并以独立情景测试检查工具路由、材料使用和真实性。

本次不购买机票酒店、不批量下载整站、不改全局账号的长期自动发布策略，也不创建新远程仓库。用户指定源码目录为 `C:/Users/junte/Code/travel-planner-skill`，该目录已有用户仓库和origin；在新分支就地编写、验证和推送，并联接到本机技能目录。
