# 小红书、B站与地图取材

## 浏览器

每次开始浏览前，按已安装 `ego-browser/SKILL.md` 运行 `ego-browser skill`，完整读取匹配版本指南。一个旅行任务复用一个TaskSpace；地图、小红书、B站和飞猪可使用同空间的不同Page，不为失败或登录新建替代空间。每轮脚本写入新的UTF-8 `.mjs`，Windows使用ASCII的 `await import('file:///.../round-01.mjs')` 入口，不能把中文脚本管道送入CLI。

先观察页面，再用语义定位选择搜索结果；截图、文件下载和浏览器内请求使用指南中实际提供的API。Ego有登录会话时直接使用，不另行读取浏览器数据库或导出Cookie。出现权限、登录、验证码或USER_CONTROL时停止浏览器操作，说明需要用户处理的具体项目；明确继续后恢复原空间。

## 按景点搜索

先确定POI的城市、正式名称与位置，避免同名景点混用。搜索词可组合“景点＋季节/带娃/停车/步行/预约”，不要只靠单条高赞笔记。至少保留相关的实际原文链接与可见信息；搜索结果摘要没有打开验证时记录为摘要证据。

小红书材料适合呈现作者体验、机位或注意事项。夏季笔记不能证明冬季开放，单个作者排队十分钟不能写成保证等待时间。B站视频核对景点、画面季节、发布时间和来源作者，影视片段或搬运合集不因为标题相符就成为现场实拍依据。

## 截图与片段

- 优先截取与当前论点直接有关的可见区域，保留景点、作者或清晰的旁注出处；移除无关账户信息不应改写原文或裁掉水印。
- 截图保存到任务 `assets/`，同时记录标题、作者、原文链接、可见发布日期、截图时间和用途。整篇笔记的长图不适合直接缩成一张视频页；选必要片段并由旁白解释。
- 视频通过平台提供的下载、作者授权文件、用户素材或可访问的公开媒体获取，不绕过DRM、付费、访问限制或验证码。记录原视频起止时间；可合法取得文件但缺重用依据时仍需判断使用范围。
- 不移除水印或署名，不将原视频背景音乐混进统一旁白。必要短引述须服务于具体介绍/评论并标明来源；不能仅以“几秒钟”自动认定可用。大段转载/宣传性拼接选择许可素材或取得明确依据。
- 只拿到链接时保存 `status: linked_only`；下载失败写 `blocked`；实际有本地文件才可写 `captured`。只将拟实际使用的、材料依据已记录的文件放进混合媒体清单。

来源记录示意（不是实际已取得的素材）：

```json
{
  "id": "S12", "platform": "xiaohongshu", "status": "linked_only",
  "title": "笔记实际标题", "author": "页面可见作者",
  "url": "原文的规范公开链接", "published_at": null,
  "captured_at": "实际获取时间", "supports": ["作者描述的步行体验"],
  "limits": "非官方营业依据，未取得可用于视频的截图文件"
}
```

地图取材要保留实际路线和地图署名；报价取材要保留日期及计价条件。素材与查询不必为了视频都使用浏览器截图：无法获取时用可追溯查询结果制作原创卡片，并把它标成整理图，而非伪造网页或地图。
